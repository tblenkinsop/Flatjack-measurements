# Flatjack-measurements
This repository contains measurements of in situ stress (MPa) recorded by the flatjack method
at four sites in England: Ardley Fields Farm, Daglingworth, Cadeby and Thrislington.
Each sheet shows the individual measurements for flatjacks in each orientation at each site.
Flatjack Az: Degrees is the azimuth of the flatjack
s Az: Radians is the orientation of the normal stress in radians
